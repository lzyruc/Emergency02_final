## 2. 离散导航系统

### 2.1 定位与适用范围

`NavigationGraph` 是上层 Agent（状态机、任务规划器等）调用导航能力的统一入口。上层只需要
使用语义节点名称，不需要了解节点之间具体包含多少次 `move_by` 底盘动作。

典型调用关系：

```text
状态机 / Agent
      |
      | moveTo("emergency.point2", correct=True)
      v
NavigationGraph（状态、最短路、动作编排、失败返回）
      |
      v
TienYi2Pro 底盘控制器
```

此外，考虑到误差，保留视觉调整接口，供上层进行小范围机体系微调：

```python
moveBy(
    x: float,
    y: float,
    theta: float,
    *,
    correct: bool = True,
) -> dict[str, float]
```

- `x`：机器人前方为正，单位为米。
- `y`：机器人左方为正，单位为米。
- `theta`：逆时针为正，单位为度。
- `correct`：默认执行最终实测位姿补偿；宽敞区域传 `False` 跳过。
- 返回值：微调后的内部逻辑位姿。

### 2.2 与 SLAM 地图融合

逻辑地图用于描述语义节点、节点拓扑和预定义运动关系，不承担环境建图和全局定位功能。
逻辑位姿主要用于动作编排和状态记录，可以结合底盘 SLAM 位姿、视觉定位或固定标志物进行
节点级校正。

SLAM 地图由晓悟底盘的内置建图与定位功能维护。`NavigationGraph` 将逻辑节点位姿转换为
当前 SLAM 地图坐标，用于 `correct=True` 时的最终小范围到点校正。

### 2.3 商超场景动作规则（v0.3）

当前实机验收主要使用 `move_by` 离散导航，并通过实时 SLAM pose 做关键位置与朝向校正：

- `start_point`、`hub_left`、`hub_center`、`hub_right` 到位后校正两轮。
- `start_point` 对准启动时记录的 map pose；三个 hub 的位置对准逻辑节点，朝向取当前最近的
  逻辑正交方向（`0°/90°/180°/270°`），避免不必要的偏航。
- 到达 `recognize_left`、`recognize_right` 前先旋转、再平移，避免靠近桌面后原地旋转。
- 同一排 `leftN` 点之间先朝逻辑 `-y`（`270°`）再横移；同一排 `rightN` 点之间先朝逻辑
  `+y`（`90°`）再横移。正反向移动保持同一朝向，仅横移方向相反。
- `centerN` 和跨排连接不使用货架横移规则。

位置误差小于 `20 mm` 或角度误差小于 `1°` 时不发送对应微调命令，以满足底盘 API 的最小
动作约束。识别点与货架规则通过 `NavigationGraph` 构造参数配置，不是所有场景的硬编码默认值。

从 v0.3.1 起，关键点校正的 `move_by` 如果返回 `2001`，会根据失败后的实时 SLAM pose 做
几何复核：位置误差不超过 `5 cm` 或角度误差不超过 `1°` 时按软成功继续。仍未到位或错误不属于
`2001 ACTION_FAILED` 时不会吞掉异常。

## 3. 建图流程

同学实际运行时只需要阅读本部分。

### 3.1 进入工程目录

```bash
cd /home/nvidia/X-humanoid
```

运行真实动作前，确认机器人定位正常、急停可用，并清空移动区域内的人员和障碍物。

### 3.2 记录路线

先进行 dry-run，熟悉交互但不移动机器人：

```bash
PYTHONPATH=. python3 -m agent.navigation.tools.record_navigation
```

确认无误后真实记录：

```bash
PYTHONPATH=. python3 -m agent.navigation.tools.record_navigation --execute
```

record 默认将底盘最大线速度限制为 `0.2 m/s`，可通过 `--linear-speed` 临时覆盖。

不指定文件名时，记录自动保存在 `agent/navigation/data/logs/`，文件名包含当前时间戳。

record 会在发送每个动作前检查目标逻辑坐标，只允许：

```text
0.0 <= x <= 3.7 m
-2.7 <= y <= 2.7 m
```

越界动作会被拒绝，不会写入动作列表，也不会发送到底盘。

也可以指定记录文件：

```bash
PYTHONPATH=. python3 -m agent.navigation.tools.record_navigation \
  agent/navigation/data/logs/scene_route.json \
  --execute
```
